# Subscriptions Tables (which table to use)

Status of each table in this family:

- `subscriptions`: STALE (not the declared current table) -> read [schemas/subscriptions]
- `subscriptions_legacy_stripe`: DEPRECATED (deprecated by decisions/adr-017-subscriptions-v3.md) -> read [schemas/subscriptions_legacy_stripe]
- `subscriptions_staging`: INTERNAL (internal per decisions/adr-017-subscriptions-v3.md) -> read [schemas/subscriptions_staging]
- `subscriptions_v3`: CURRENT (declared authoritative by decisions/adr-017-subscriptions-v3.md) -> read [schemas/subscriptions_v3]
