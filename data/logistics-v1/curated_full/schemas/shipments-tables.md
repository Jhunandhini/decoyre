# Shipments Tables (which table to use)

Status of each table in this family:

- `shipments`: STALE (not the declared current table) -> read [schemas/shipments]
- `shipments_legacy_tms`: DEPRECATED (deprecated by decisions/adr-021-shipments-v2.md) -> read [schemas/shipments_legacy_tms]
- `shipments_staging`: INTERNAL (internal per decisions/adr-021-shipments-v2.md) -> read [schemas/shipments_staging]
- `shipments_v2`: CURRENT (declared authoritative by decisions/adr-021-shipments-v2.md) -> read [schemas/shipments_v2]
