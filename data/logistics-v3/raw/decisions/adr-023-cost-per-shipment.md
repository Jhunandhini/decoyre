# ADR-023: change of cost per shipment definition

Status: Accepted

## Context

Return trips were double counted.

## Decision

From this quarter on, everyone should follow the finance team's page "Cost per shipment - finance definition". Please ignore the 2023 analytics write-up "How we calculate cost per shipment" when building reports.
